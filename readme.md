# My_portfolio

> Personal portfolio website of **Siddharth Shetty** — Computer Science Engineering, AI/ML & Software Development.

## 🚀 Built With

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & Lottie
- **Icons**: React Icons
- **Deployment**: Ready for Vercel / Netlify / GitHub Pages

## 🛠️ Features

- **Hero Section**: Personal introduction and call-to-actions
- **Skills & Experience**: Technical skill categorization & professional experience
- **Education**: AMC Engineering College, Bengaluru
- **Achievements**: Verified hackathon & innovation challenge track record
- **Projects Showcase**: Interactive carousel showcasing AI, IoT, web, and data projects
- **Open Source**: Public repositories and GitHub integration
- **Activities**: Tech communities, bootcamps, and developer programs
- **Contact**: Direct links to LinkedIn, GitHub, LeetCode, and HackerRank

## 💻 Local Setup & Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
